# 📡 Інструкція користувача ZVIAZKIVETS Antenna Tuner

Цей інструмент дозволяє створити точний профіль КСХ (SWR) вашої антени для прошивки **ZVIAZKIVETS**. Це необхідно для того, щоб система автоматично уникала каналів, на яких ваша антена працює погано, зберігаючи відеопередавач (VTX) та забезпечуючи стабільний зв'язок.

---

## 🖥 Частина 1. Як користуватись сайтом

Веб-інтерфейс дозволяє візуалізувати роботу антени та згенерувати код для прошивки.

### 1. Візуальний графік
* **Осі:** По горизонталі — частота (4800–6200 MHz), по вертикалі — КСХ (від 1.0 до 3.0).
* **Редагування:** Ви можете "тягати" білі точки мишкою (або пальцем), щоб виставити реальне значення КСХ для конкретної частоти.
* **Інформація:** При наведенні на точку ви побачите точну частоту, КСХ та назву каналу (наприклад, `F1`, `R3`).
* **Навігація:** Використовуйте колесо мишки для **зуму** по горизонталі. Затисніть ліву кнопку миші, щоб рухати графік вліво-вправо.

### 2. Використання Пресетів (Шаблонів)
Якщо у вас популярна антена (наприклад, Rush Cherry, TrueRC Core 5.8 і тд.), ви можете завантажити готовий профіль:
1.  Знайдіть випадаючий список **"📂 Обрати пресет..."**.
2.  Оберіть вашу антену.
3.  Натисніть **ОК** у вікні підтвердження. Графік оновиться автоматично.

### 3. Ручне введення даних (CSV)
У полі **"КСХ формату ZVIAZKIVETS"** ви можете вручну вставити список значень КСХ (через кому).
* Це корисно, якщо ви хочете скопіювати профіль з іншого пристрою.
* Після вставки графік автоматично оновиться.

## 🛠 Частина 2. Аналіз антени (NanoVNA / LiteVNA)

Для отримання точних даних рекомендовано використовувати векторний аналізатор мереж (VNA).

### Крок 1. Підготовка ПЗ та обладнання
Вам знадобиться:
1.  Прилад **NanoVNA** (V2, H, H4) або **LiteVNA**.
2.  Кабель USB для підключення до ПК.
3.  Програма **NanoVNA Saver** для комп'ютера.

📥 **Завантажити NanoVNA Saver:** [GitHub Releases](https://github.com/NanoVNA-Saver/nanovna-saver/releases) (обирайте файл `.exe` для Windows).

> **Примітка:** Якщо ПК не бачить прилад, встановіть драйвери **CH340** або **CP210x**.

### Крок 2. Підключення та Налаштування
1.  Підключіть VNA до комп'ютера та запустіть NanoVNA Saver.
2.  Натисніть **Rescan**, оберіть COM-порт і натисніть **Connect to device**.
3.  У блоці **Sweep Settings** (зліва) виставте параметри для FPV:
    * **Start:** `4800 MHz`
    * **Stop:** `6200 MHz`
    * **Segments:** `5` (Це важливо! Це дасть високу точність графіку).

### Крок 3. Калібрування (Критично важливо!) ⚠️
Без калібрування виміри будуть невірними. Використовуйте калібрувальний набір (ковпачки), що йде в комплекті.

**Куди вкручувати?**
* Якщо антена підключається прямо в прилад — калібруйте роз'єм **CH0 (S11)** на приладі.
* Якщо використовуєте пігтейл (подовжувач) — **калібруйте на кінці кабелю!**

**Процедура:**
1.  У програмі натисніть **Calibration** -> **Reset Calibration**.
2.  **SHORT (Замкнений):** Ковпачок з голкою всередині, дзвониться мультиметром.
    * Вкрутіть -> натисніть `Short` -> чекайте завершення.
3.  **OPEN (Розрив):** Порожній ковпачок без голки.
    * Вкрутіть -> натисніть `Open`.
4.  **LOAD (Навантаження 50 Ом):** Ковпачок з голкою та пластиком всередині (показує 50 Ом).
    * Вкрутіть -> натисніть `Load`.
5.  Натисніть **Apply** (або Save).

### Крок 4. Вимірювання та Експорт
1.  Вкрутіть вашу антену в порт **CH0 (TX)**.
2.  Натисніть кнопку **Sweep**.
3.  Переконайтесь, що графік виглядає адекватно (є "ями", де КСХ падає до 1.2–1.5).
    * *Порада:* Щоб краще бачити графік, натисніть `Display Settings` -> `Axis Limits` -> `Max VSWR: 4`.
4.  Збережіть файл аналізу:
    * Натисніть **Files** (або Touchstone).
    * Оберіть **Export file...** (формат `.s1p`).
    * Збережіть файл на диск (наприклад, `my_antenna.s1p`).

## 🚀 Частина 3. Імпорт у ZVIAZKIVETS

1.  Поверніться на сайт **ZVIAZKIVETS Antenna Tuner**.
2.  Знайдіть кнопку **"📡 Імпорт файлу NanoVNA (.s1p)"**.
3.  Оберіть збережений файл `my_antenna.s1p`.
4.  Система автоматично:
    * Прочитає файл.
    * Знайде значення КСХ для всіх потрібних частот (5.8 GHz).
    * Побудує графік.
5.  Скопіюйте отриманий **КСХ формату ZVIAZKIVETS** для прошивки.

> **Порада:** Якщо після імпорту графік "стрибає" або показує занадто високі значення, перевірте якість контакту роз'єму (SMA vs RP-SMA) та перекалібруйте NanoVNA.
